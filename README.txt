RELATÓRIO ESCOLAR — VERSÃO FIEL AO MODELO

Abra index.html no Chrome ou Edge.

1. Preencha os dados do aluno.
2. Informe o período.
3. Clique em Criar dias do período.
4. Preencha os registros.
5. Use Atualizar prévia para conferir.
6. Use Salvar PDF.

O gerador usa A4, margens fixas, tabela do cabeçalho, cores, tipografia e estrutura visual baseadas no PDF fornecido.
O logotipo foi extraído do documento de referência fornecido pelo usuário.

Para obter a impressão mais fiel:
- papel A4;
- escala 100%;
- margens: nenhuma;
- cabeçalhos e rodapés do navegador: desativados;
- gráficos/imagens de fundo: ativados, se o navegador mostrar essa opção.

Observação: a fidelidade final pode variar alguns milímetros conforme o motor de impressão do navegador. O conteúdo e a geometria foram feitos para A4.
